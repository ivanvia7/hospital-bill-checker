Hospital bill checker

Compare each line of your hospital bill with the prices the hospital itself posts.

Your files stay on your computer The bill and the price file are read inside this browser tab. Nothing is uploaded or saved anywhere. Closing the tab clears them. See the code

Open , find your hospital's location-name and download the file after mrf-url:. Unzip it first if it is a .zip.

2. Check your bill

A 500 MB price file takes about 40 seconds.
